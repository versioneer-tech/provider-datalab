# Provider Datalab

Declare a team's users, virtual Kubernetes clusters, databases, and registries
in one `Datalab` resource. The platform supplies identity, storage, and network
settings through an EnvironmentConfig.

Platform operators start with [Installation](how-to-guides/installation.md).
For team workflows, see [Virtual clusters](how-to-guides/vcluster.md) and
[Use a Datalab](how-to-guides/usage_concepts.md).
Use [Sandboxes](how-to-guides/sandboxes.md) for command execution and durable
workspaces, and [Connections](how-to-guides/connections.md) for service credentials.
The [API reference](reference-guides/api.md) describes resource fields and status.
